# claude-cli-mod

Mod para o Claude Code: menu no canto inferior, modo Zen com barra de progresso, temas de
terminalcolors.com, controles de modelo, effort e modo de permissão, e status line.

Mantido por [iagopadilha](https://github.com/iagopadilha).

## Instalar

```
/plugin marketplace add iagopadilha/claude-cli-mod
/plugin install claude-cli-mod@iagopadilha-mods
```

Abra o menu com o comando `/claude-cli-mod` (abas: zen, themes, mode, status).

## Notas

- Os temas baixados ficam em `~/.claude/claude-cli-mod/themes`.
- A ferramenta de progresso do Zen se chama `zen_progress`.

## Créditos

Baseado em um mod liberado publicamente pelo autor original, Jhonatan de Souza, em vídeo no YouTube.
